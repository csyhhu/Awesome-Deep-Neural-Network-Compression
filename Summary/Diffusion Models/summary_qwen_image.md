> **论文**: Qwen-Image Technical Report

> **作者**: Qwen Team (Alibaba Cloud)  
> **核心领域**: 图像生成、扩散模型、文本渲染、图像编辑

## 一、论文核心贡献

Qwen-Image 是通义系列中的图像生成基础模型，旨在解决两大核心挑战：

1. **复杂文本渲染**：在生成图像中准确渲染多行文本、段落级语义及细粒度文字细节，尤其支持中文等表意文字
2. **精准图像编辑**：在保持语义一致性和视觉保真度的同时，实现精确的图像编辑操作

### 主要贡献点

| 贡献 | 描述 |
|------|------|
|  superior 文本渲染 | 支持英文（拼音文字）和中文（表意文字）的高保真渲染，包括多行布局、段落级语义 |
| 一致性图像编辑 | 通过增强的多任务训练范式，在编辑操作中同时保持语义含义和视觉真实感 |
| 跨基准领先 | 在 GenEval、DPG、OneIG-Bench 等多个基准上全面超越现有模型 |

## 二、模型架构

### 2.1 三大核心组件

Qwen-Image 由三个协同工作的核心组件构建：

```
┌─────────────────────────────────────────────────────────┐
│                    Qwen-Image 架构                        │
│                                                          │
│  ┌──────────────┐   ┌──────────────┐   ┌─────────────┐  │
│  │ Qwen2.5-VL   │   │    VAE       │   │   MMDiT     │  │
│  │ (条件编码器)  │──▶│  (图像分词器) │──▶│  (骨干扩散)  │  │
│  └──────────────┘   └──────────────┘   └─────────────┘  │
│        文本特征提取      │ 图像压缩/解码     │ 联合建模     │
└─────────────────────────────────────────────────────────┘
```

### 2.2 Multimodal Large Language Model (MLLM)

- **选用 Qwen2.5-VL** 作为文本特征提取模块，原因：
  1. 语言和视觉空间已对齐，更适合文生图任务
  2. 保留强语言建模能力
  3. 支持多模态输入，实现图像编辑等扩展功能
- 设计了针对 **纯文本输入** 和 **图文输入** 的差异化系统提示

### 2.3 Variational AutoEncoder (VAE)

- 采用 **Wan-2.1-VAE** 的架构，使用单编码器+双解码器设计
- 编码器兼容图像和视频，解码器分别针对各模态优化
- **仅微调图像解码器**，在文本丰富的图像语料上训练
- 训练策略：使用重建损失 + 感知损失（动态调整比例），不使用对抗损失
- **效果**：在文本丰富图像上重建质量显著优于其他 VAE

### 2.4 Multimodal Diffusion Transformer (MMDiT)

- 采用 MMDiT 架构联合建模文本和图像
- **核心创新：MSRoPE（Multimodal Scalable RoPE）**

#### MSRoPE 位置编码

| 方法 | 描述 | 问题 |
|------|------|------|
| 传统 MMDiT | 文本 token 直接拼接在展平的图像位置编码后 | 无分辨率缩放能力 |
| Scaling RoPE (Seedream 3.0) | 图像位置编码移至中心区域，文本视为 [1, L] 的 2D token | 文本和图像某些行同构，难以区分 |
| **MSRoPE (Ours)** | 文本沿对角线拼接，所有文本位置 ID 相同 | 兼顾分辨率缩放和文本-图像区分 |

**MSRoPE 的优势**：
- 图像侧享受分辨率缩放优势
- 文本侧保持与 1D-RoPE 功能等价
- 无需确定文本的最优位置编码

### 2.5 架构配置

| 配置 | VLM (ViT/LLM) | VAE (Enc/Dec) | MMDiT |
|------|---------------|---------------|-------|
| 层数 | 32 / 28 | 11 / 15 | 60 |
| 注意力头 | 16/16 / 28/4 | - | 24/24 |
| 头维度 | 80 / 128 | - | 128 |
| 中间层维度 | 3,456 / 18,944 | - | 12,288 |
| Patch/缩放因子 | 14 / - | 8×8 / 8×8 | 2 |
| **参数量** | **7B** | **54M / 73M** | **20B** |

## 三、数据工程

### 3.1 数据收集

系统性收集了数十亿级图文对，四大类别：

```
数据集组成：
├── Nature (自然) - 55%
│   ├── Objects (物体)
│   ├── Landscape (风景)
│   ├── Cityscape (城市)
│   ├── Plants (植物)
│   ├── Animals (动物)
│   ├── Indoor (室内)
│   └── Food (美食)
├── Design (设计) - 27%
│   ├── Posters (海报)
│   ├── User Interfaces (界面)
│   ├── Presentation Slides (幻灯片)
│   └── 各类艺术形式
├── People (人物) - 13%
│   ├── Portrait (肖像)
│   ├── Sports (运动)
│   └── Human Activities (活动)
└── Synthetic Data (合成数据) - 5%
    └── 纯文本渲染合成（非 AI 生成）
```

### 3.2 七阶段数据过滤流水线

| 阶段 | 关注点 | 关键操作 |
|------|--------|----------|
| **Stage 1** | 初始预训练数据筛选 | 坏文件过滤、分辨率过滤、去重、NSFW 过滤 |
| **Stage 2** | 图像质量增强 | 旋转过滤、清晰度过滤、亮度/饱和度/熵/纹理过滤 |
| **Stage 3** | 图文对齐改进 | 中文 CLIP 过滤、SigLIP 2 过滤、Token 长度过滤 |
| **Stage 4** | 文本渲染增强 | 按语言分类（英文/中文/其他/无文本）、引入合成数据 |
| **Stage 5** | 高分辨率优化 (640p) | 图像质量、美学、异常元素（水印/二维码）过滤 |
| **Stage 6** | 类别平衡与肖像增强 | 层次分类、关键词检索增强、面部马赛克过滤 |
| **Stage 7** | 平衡多尺度训练 (640p+1328p) | 层次分类体系、质量优选、重采样平衡 |

### 3.3 数据标注

- **统一标注框架**：同时生成详细描述和结构化元数据（JSON 格式）
- 标注内容包括：
  - 图像描述（对象属性、空间关系、环境、可见文字原文）
  - 图像类型、风格
  - 水印列表
  - 异常元素检测

### 3.4 数据合成

针对真实图像中文字内容的长尾分布（尤其是中文），设计三种合成策略：

| 策略 | 方法 | 目的 |
|------|------|------|
| **Pure Rendering** | 在纯色背景上渲染文本段落 | 学习字符识别和生成 |
| **Compositional Rendering** | 将文本合成到真实场景中 | 学习真实场景中的文本理解 |
| **Complex Rendering** | 程序化编辑模板（PPT/UI） | 学习复杂布局和多文本元素 |

## 四、训练策略

### 4.1 预训练

#### Flow Matching 训练目标

```
x_t = t·x_0 + (1-t)·x_1    # 中间状态
v_t = x_0 - x_1             # 目标速度

Loss = MSE(v_θ(x_t, t, h), v_t)
```

其中：
- `x_0`：VAE 编码后的图像潜变量
- `x_1`：标准高斯噪声
- `h`：MLLM 提取的文本/条件特征
- `t`：logit-normal 分布采样的时间步

#### Producer-Consumer 框架

```
┌──────────────┐     HTTP/RPC      ┌──────────────┐
│  Producer    │ ════════════════▶  │  Consumer    │
│  (数据端)    │   异步零拷贝传输    │  (训练端)    │
│              │                    │              │
│ • 数据过滤   │                    │ • 4-way 张量并行│
│ • VAE 编码   │                    │ • Megatron 框架│
│ • MLLM 编码  │                    │ • 仅做模型训练  │
│ • 缓存分桶   │                    │              │
└──────────────┘                    └──────────────┘
```

#### 分布式训练优化

- **混合并行策略**：数据并行 + 张量并行（Transformer-Engine 库）
- **头部并行**：多头自注意力按头并行，减少同步开销
- **分布式优化器**：All-Gather 使用 bfloat16，Reduce-Scatter 使用 float32
- **禁用 Activation Checkpointing**：虽节省 11.3% 显存，但增加 3.75× 耗时

#### 渐进式训练策略

| 策略 | 描述 |
|------|------|
| 分辨率提升 | 256p → 640p → 1328p |
| 文本整合 | 非文本 → 简单文本 → 复杂文本 |
| 数据精炼 | 大规模数据 → 精选高质量数据 |
| 分布平衡 | 不平衡 → 按领域/分辨率平衡 |
| 合成增强 | 真实数据 → 引入合成数据 |

### 4.2 后训练

#### Supervised Fine-Tuning (SFT)
- 层次化语义类别数据集
- 人工标注筛选清晰、细节丰富、明亮、写实的图像

#### Reinforcement Learning (RL)

**DPO (Direct Preference Optimization)**
- 用于大规模在线偏好建模（一步 flow-matching）
- 基于 flow matching 训练目标构建 DPO 损失

```
L_DPO = -E[log σ(-β·(Diff_policy - Diff_ref))]
```

**GRPO (Group Relative Policy Optimization)**
- 用于小规模精细 RL 微调
- 基于 Flow-GRPO 框架，使用 SDE 采样增加随机性
- 优势函数：组内归一化奖励

### 4.3 多任务训练

#### 图像编辑 (TI2I) 任务

```
双路输入：
├── 语义路径：Qwen2.5-VL 编码图像 → 文本流（视觉语义嵌入）
└── 重建路径：VAE 编码器编码图像 → 图像流（像素级重建嵌入）

MSRoPE 扩展：引入 frame 维度区分编辑前后的图像
```

**系统提示设计**：描述输入图像的关键特征，并说明如何根据用户指令修改图像。

## 六、定性分析

### 6.1 英文文本渲染
- **长段落渲染**：仅 Qwen-Image 和 GPT Image 1 能清晰渲染长英文段落
- **复杂多位置文本**：Qwen-Image 能在 7 个不同位置正确渲染文本，其他模型常遗漏或扭曲

### 6.2 中文文本渲染
- **对联生成**：Qwen-Image 准确生成预期的中文对联，其他模型遗漏或扭曲字符
- **复杂场景中文**：在动漫场景、手写文本等复杂场景中，Qwen-Image 是唯一能准确渲染长文本的模型

### 6.3 多物体与空间关系
- **十二生肖生成**：准确生成所有指定动物，保持正确位置和毛绒风格
- **空间交互**：准确描绘人物间的攀爬互动、人与鸽子、怀表与杯柄的空间关系

### 6.4 图像编辑
- **姿态操作**：保持发丝等细节、背景结构一致性、服装细节
- **链式编辑**：在多步编辑中保持结构特征和纹理细节
- **新视角合成**：唯一能在复杂真实场景中保持全局一致性的模型

## 七、核心创新与启示

### 7.1 技术创新

1. **MSRoPE 位置编码**：通过将文本沿图像对角线拼接，兼顾分辨率缩放和图文区分
2. **双编码器图像编辑**：语义（MLLM）+ 重建（VAE）双路径，平衡语义一致性和视觉保真度
3. **渐进式课程学习**：从非文本到文本、从简单到复杂、从低分辨率到高分辨率
4. **图文数据合成流水线**：三种渲染策略解决中文等低资源语言的长尾问题
5. **Producer-Consumer 框架**：解耦数据预处理和模型训练，支持大规模分布式训练

### 7.2 理念创新

1. **重新定义图像生成的优先性**：从追求"逼真"转向强调文本-图像精确对齐
2. **生成式理解**：用生成框架执行经典理解任务（深度估计等），从直接推理转向分布推理
3. **跨模态泛化**：从 2D 图像到 3D/视频，展示了图像基础模型的跨模态能力
4. **理解-生成统一**：Qwen-Image（生成）+ Qwen2.5-VL（理解）构成多模态 AI 的两大支柱

### 7.3 实用价值

- 为开发者和研究者提供了强大的开源图像生成模型
- 在中文文本渲染方面实现了重大突破，支持更广泛的应用场景
- AI Arena 平台开放，任何人可参与模型对比

---

## 八、总结

Qwen-Image 不仅是一个先进的图像生成模型，更代表了多模态基础模型构建范式的转变：

1. **技术层面**：通过 MSRoPE、双编码器、渐进式训练等创新，在文本渲染（尤其是中文）和图像编辑上实现了显著突破
2. **理念层面**：挑战了生成模型在感知、界面设计和认知建模中的角色，推动视觉理解与生成的边界进一步模糊
3. **实践层面**：为实际应用提供了高价值的开源方案，从文本渲染到图像编辑再到 3D 理解

> **一句话总结**：Qwen-Image 通过全面的数据工程、渐进式学习策略和创新的多任务训练范式，成为在复杂文本渲染（特别是中文）和精准图像编辑方面均达到领先水平的开源图像生成基础模型。
