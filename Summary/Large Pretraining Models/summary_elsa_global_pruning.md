# ELSA: 突破 LLM 稀疏性壁垒的全局剪枝方法

> **论文**: The Unseen Frontier: Pushing the Limits of LLM Sparsity with Surrogate-Free ADMM  
> **arXiv**: https://arxiv.org/abs/2510.01650  
> **作者**: Kwanhee Lee, Hyeondo Jang, Dongyeop Lee, Dan Alistarh, Namhoon Lee (POSTECH & ISTA)  
> **机构**: POSTECH, 奥地利科学技术学院 (ISTA)

---

## 📌 核心摘要

本文提出了一种名为 **ELSA** (Extreme LLM sparsity via Surrogate-free ADMM) 的新型剪枝框架，旨在突破当前大语言模型 (LLM) 剪枝方法在 50-60% 稀疏度处的"稀疏性壁垒"。ELSA 基于 **ADMM (交替方向乘子法)** 约束优化技术，直接优化全局训练目标（下一个 token 预测损失），而非使用传统的逐层重建误差代理目标。

**核心成果**：在 LLaMA-2-7B 模型上，ELSA 在 90% 稀疏度下实现了 **26.97** 的 Wiki 困惑度，而已有最优方法的困惑度通常达到数百甚至数千。在 95% 稀疏度下仍保持稳定性能，并实现了 **3.98× 推理加速** 和 **7.80× 内存压缩**。

## 🎯 研究动机与问题

### 当前方法的瓶颈

当前主流的 LLM 剪枝方法（如 SparseGPT、Wanda、ALPS 等）主要采用 **逐层重建误差最小化 (Layer-wise Reconstruction Error Minimization, REM)** 范式：

```
公式 (1) —— 全局剪枝目标：
  x* = argmin f(x)  s.t. ‖x‖₀ ≤ k

公式 (2) —— 逐层 REM 方法（实际采用的）：
  x* = {x_i* for i=1,...,L}
  其中 x_i* = argmin f̃(x_i) s.t. ‖x_i‖₀ ≤ k_i
```

### 逐层 REM 的三大缺陷

| 缺陷 | 描述 |
|------|------|
| **1. 近似误差累积** | 逐层子问题本身是 NP-hard 的，不可避免地引入近似误差，这些误差在逐层拼接时逐级累积 |
| **2. 次优性** | 强制逐层特征匹配预训练网络，限制了搜索空间；各层独立优化，后续层改变时前面层保持固定 |
| **3. 代理目标错位** | 优化的是重建误差 f̃ 而非真实目标 f（语言建模能力），即使完美求解 REM 也无法保证获得 (1) 的最优解 |

**关键论点**：所谓的"稀疏性壁垒"并非剪枝本身的固有局限，而是当前代理目标公式的产物。

## 💡 方法：ELSA 框架

### 1. 基于 ADMM 的无代理全局剪枝

**核心思想**：通过引入辅助变量 z，将稀疏约束与训练目标解耦：

```
min_{x,z} f(x) + I_S(z)   s.t. x = z
```

其中 S = {z ∈ ℝᵈ | ‖z‖₀ ≤ k} 为稀疏集，I_S(z) 为指示函数。

**增广拉格朗日函数**：

```
L_λ(x, z, u) = f(x) + I_S(z) + (λ/2)‖x - z + u‖₂² - (λ/2)‖u‖₂²
```

**ADMM 三步迭代**：

| 步骤 | 更新公式 | 含义 |
|------|----------|------|
| **x-更新** | x^{t+1} = argmin_x (f(x) + (λ/2)‖x - z^t + u^t‖²) | 最小化训练目标，同时逼近稀疏变量 z |
| **z-更新** | z^{t+1} = Π_S(x^{t+1} + u^t) | 投影到稀疏集 S（保留幅度最大的 k 个参数） |
| **u-更新** | u^{t+1} = u^t + x^{t+1} - z^{t+1} | 对偶变量更新，累积残差 |

### 2. 目标感知投影 (Objective-aware Projection)

标准 z-更新使用欧几里得距离投影，仅基于参数幅度选择保留项。ELSA 引入了 **Hessian 矩阵** 来对齐投影与真实目标 f：

```
z^{t+1} = argmin_{z∈S} Σᵢ F̂ᵢᵢ · (zᵢ - (xᵢ^{t+1} + uᵢ^t))²
```

其中 F̂ 是 Fisher 信息矩阵（Hessian 的 Gauss-Newton 近似），对角元素 F̂ᵢᵢ 衡量每个参数对目标函数的贡献。

**优势**：将简单的幅度剪枝升级为 **Optimal Brain Surgeon 风格** 的贡献度剪枝，且 Adam 优化器的二阶矩估计可直接提供 F̂，无额外开销。

### 3. 低精度状态扩展 (ELSA-L)

为扩展到超大模型（27B），ELSA-L 引入量化/反量化循环：

- **量化 Q(z)** → (z_q, s)：将高精度张量映射为低精度存储对
- **反量化 R(z_q, s)** → s · z_q：从存储对重建高精度张量
- 使用 **INT8/FP8** 存储辅助变量 (u, z)，**adam8bit** 优化器进行 x-更新
- 相比标准 ELSA 减少 **55%** 内存占用

## 📐 理论分析

### 收敛性保证

基于以下假设：
1. **有界下界**：f 在 S 上有下界
2. **β-平滑性**：f 的梯度是 β-Lipschitz 连续的
3. **μ-弱凸性**：f 是 μ-弱凸的

**定理 1 (ELSA 收敛)**：当 λ 足够大（满足 λ⁻¹β² - (λ-μ)/2 < 0），ELSA 的极限点 x̄ 是 (1) 的 λ-驻点。

**定理 2 (ELSA-L 收敛)**：当参数满足：

```
β²/λ + β(λ+β)γ/λ + γ²(λ+β)/2 - (1-γ)²(λ-μ)/2 < 0
```

ELSA-L 的极限点同样是 (1) 的 λ-驻点。

## 💬 个人理解与点评

### 技术亮点

1. **范式转变**：从"分而治之"的逐层 REM 转向端到端的全局优化，这是 LLM 剪枝领域的重要方法论突破
2. **理论深度**：不同于大多数基于经验直觉的剪枝方法，ELSA 建立在成熟的 ADMM 优化理论之上，并提供了收敛性保证
3. **实用价值**：90%+ 稀疏度下的显著性能保持，使得在实际部署中利用稀疏矩阵运算实现真实的加速和内存节省成为可能

### 潜在限制

1. **计算成本**：虽然 ELSA 的单次剪枝成本（7.12 GPU-hours for 7B/90%）高于一次性方法，但剪枝是一次性操作，模型会被反复使用
2. **当前仅支持非结构化稀疏**：对于需要硬件支持的 N:M 结构化稀疏，性能与现有方法相当（仅 50% 稀疏度）
3. **对优化器状态精度有要求**：低精度变体 ELSA-L 虽大幅节省内存，但精度折损对极小模型的影响尚待验证

## 💬 深度问答 (Q&A)

### Q1: 如何理解 Objective-aware Projection 中的公式？它替换了原来的 Z 更新吗？

**A: 它没有替换 Z 更新，而是修改了 Z 更新中的「投影操作」的度量（metric）。**

为了理解，我们先回顾 ADMM 中 z-更新的**原始形式**（欧几里得投影）：

```
z^{t+1} = Π_S(x^{t+1} + u^t)
         = argmin_{z∈S} (λ/2)‖z - (x^{t+1} + u^t)‖₂²
```

这个投影的含义是：**在欧几里得距离下**，从所有满足稀疏约束的向量中，找到离目标向量 `x^{t+1} + u^t` 最近的那个。等价于：保留幅度 `|x_i^{t+1} + u_i^t|` 最大的 k 个参数，其余清零。这本质上就是**简单的幅度剪枝 (magnitude pruning)**。

**Objective-aware Projection 做的事情，就是把这个投影的距离度量从欧几里得距离换成由 Hessian 矩阵 H 诱导的距离：**

```
z^{t+1} = argmin_{z∈S} (1/2)(z - target)ᵀ H (z - target)
```

其中 `target = x^{t+1} + u^t`，`H` 是损失函数 f 的 Hessian 矩阵。

**关键变化**：
- **原来**：`‖z - target‖₂² = Σᵢ (zᵢ - targetᵢ)²` → 每个参数的"移动代价"相同
- **现在**：`(z - target)ᵀ H (z - target)` → 每个参数的"移动代价"由 H 加权

因此，**Z 更新的结构完全没变**——仍然是 `z^{t+1} = argmin_{z∈S} [关于 z 的函数]`——只是这个函数从欧几里得距离变成了 Hessian 加权距离。ADMM 算法的收敛性理论依然成立。

### Q2: 加了 Fisher 矩阵的更新为什么效果更好？

**A: 核心原因是它让剪枝决策与「参数对模型性能的真实贡献」对齐，而非仅看参数的绝对数值大小。**

#### 从 Hessian 的几何直觉说起

Hessian 矩阵 H = ∇²f(x) 描述了损失函数 f 在当前点的**曲率**：

- **H_ii 大** → 第 i 个参数方向上，损失函数曲线很陡峭 → 改变这个参数会导致损失大幅变化 → **这个参数很重要**
- **H_ii 小** → 第 i 个参数方向上，损失函数很平坦 → 改变这个参数对损失影响很小 → **这个参数不重要**

所以用 H 作为权重，相当于说：**优先保留那些"动一下就会让损失变化很大"的参数**。

#### Fisher 矩阵：Hessian 的高效近似

实际使用中，精确计算 Hessian 代价太高，论文使用了 **经验 Fisher 信息矩阵** F̂ 作为替代：

```
F̂ = (1/N) Σ ∇f_i · ∇f_iᵀ    (梯度外积的平均)
```

这是 Hessian 的 Gauss-Newton 近似，在实践中被广泛使用。进一步地，论文还做了两个关键简化：

1. **只使用对角元素 Diag(F̂)**：使问题在每个坐标上**可分离**，保留了原始欧几里得投影的简洁性
2. **直接复用 Adam 的二阶矩估计**：Adam 优化器中的 `v_t`（二阶矩估计量）本质上就是 Fisher 对角元素的指数移动平均，**无需额外计算开销**

#### 数学推导：为什么 F̂ᵢᵢ 权重改变了"保留哪些参数"

代入 Fisher 对角近似后：

```
z^{t+1} = argmin_{z∈S} Σᵢ F̂ᵢᵢ · (zᵢ - targetᵢ)²
```

这个目标仍然是可分离的。对于每个坐标 i，贡献为 `F̂ᵢᵢ · (zᵢ - targetᵢ)²`。

- 如果我们决定**保留**参数 i（zᵢ = targetᵢ，即 zᵢ = 0 偏差），贡献为 0
- 如果我们决定**剪枝**参数 i（zᵢ = 0），贡献为 `F̂ᵢᵢ · targetᵢ²`

所以剪枝的代价是 `F̂ᵢᵢ · targetᵢ²`。**我们应当剪枝那些代价最小的参数**——即 `F̂ᵢᵢ · targetᵢ²` 最小的 k 个参数。

这与标准幅度剪枝（仅按 `|targetᵢ|` 排序）形成对比：

| 方法 | 剪枝决策依据 | 含义 |
|------|------------|------|
| 幅度剪枝 | `|targetᵢ|` 小的剪掉 | 绝对值小的参数不重要 |
| **Fisher 加权剪枝** | `F̂ᵢᵢ · targetᵢ²` 小的剪掉 | **对损失影响小的参数剪掉** |

#### 直观示例

假设模型中有两个参数：
- 参数 A：值 = 0.5，但 F̂_AA = 1.0（对损失影响极大）
- 参数 B：值 = 2.0，但 F̂_BB = 0.01（对损失影响极小）

| 方法 | 保留哪个？ | 剪枝代价 |
|------|-----------|---------|
| 幅度剪枝 | 保留 B（值更大） | 剪 A：0.5² = 0.25 |
| Fisher 加权 | 保留 A（贡献更大） | 剪 B：0.01 × 4 = 0.04 |

显然 Fisher 加权的决策更合理——保留了对模型性能真正重要的参数。

#### 与 Optimal Brain Surgeon (OBS) 的关系

这种思想直接来源于 **OBS 算法**（LeCun et al., 1989），它是经典的基于 Hessian 的剪枝方法。ELSA 的创新在于：**在 ADMM 框架下，将 OBS 思想优雅地融入到投影步骤中**，同时利用 Adam 的二阶矩实现了零额外开销。

#### 消融实验验证

论文的消融实验定量验证了这一点：

| 稀疏度 | 无目标感知投影 (xmark) | 有目标感知投影 (checkmark) | 差距 |
|--------|----------------------|--------------------------|------|
| 70% | 29.44 | **28.24** | 1.20 |
| 80% | 40.06 | **37.50** | 2.56 |
| 90% | 65.41 | **48.69** | **16.72** |

**重要观察**：差距随稀疏度增大而急剧扩大。在 90% 稀疏度时，目标感知投影的困惑度仅为无投影版本的 **74.4%**。这是因为在高稀疏度下，错误的剪枝决策（剪掉重要参数、保留不重要参数）的代价被成倍放大。

### Q3: ELSA 是在模型训练时剪枝还是训练完成后剪枝？整个 ADMM 过程需要多少数据量和计算量？

**A: ELSA 是一种 Post-Training Pruning（训练后剪枝）方法，从预训练好的 LLM 出发进行剪枝。**

#### 剪枝时机

ELSA 不涉及模型的预训练过程。它接收一个**已经训练好的稠密 LLM**，通过 ADMM 优化直接将其剪枝到目标稀疏度。这与 SparseGPT、Wanda 等方法的范式一致——都是 post-training 压缩。

#### 数据量需求

| 用途 | 数据量 | 序列长度 | 说明 |
|------|--------|----------|------|
| 基线方法（Wanda/SparseGPT 等） | 128 序列 | 2048 | 遵循 SparseGPT 惯例 |
| **ELSA** | **32,768 数据点** | 2048 | 因 ADMM 是迭代优化，需更大数据集 |
| 评估 | C4 验证集 / WikiText2 | — | 标准语言建模评估 |

> 💡 ELSA 使用的数据量（32,768）约为基线方法（128）的 **256 倍**，这是因为迭代式优化需要更多样本来避免过拟合到小数据集。消融实验显示 NTP（下一个 token 预测）目标随数据量增加持续改进，而 REM（重建误差）目标很快饱和。

#### 计算量（以 LLaMA-2-7B @ 90% 稀疏度为例）

| 方法 | 墙钟时间 (h) | GPU 数量 | Wiki PPL | 说明 |
|------|-------------|---------|----------|------|

| SparseGPT | 0.251 | 1 | 1430 | 一次性方法 |

| Wanda+LoRA | 4.03 | 1 | 92.66 | 剪枝+LoRA 微调 |
| Wanda+Full | 1.64 | 4 | 42.40 | 剪枝+全参数微调 |
| **ELSA** | **1.78** | **4** | **26.97** | **全局优化，质量最好** |

**关键观察**：
- ELSA 的计算成本（1.78h × 4 GPU = 7.12 GPU-hours）**低于 ALPS**（12.57 GPU-hours）
- 与 Wanda+Full 微调相比，ELSA 用相似的计算量获得了**显著更好的质量**（26.97 vs 42.40）
- 虽然 ELSA 比一次性方法慢，但剪枝是**一次性操作**，模型会被反复部署使用

### Q4: ELSA 如何确定每层/每个模块的稀疏度？

**A: 主实验使用均匀稀疏度（所有层相同），同时也探索了非均匀稀疏度和结构化稀疏。**

#### 1. 均匀稀疏度（主要设置）

论文的**主要实验全部采用均匀稀疏度分配**，即对模型所有层施加相同的稀疏度约束。测试了 50%、60%、70%、80%、90% 五个等级。

这种简化设计有两个原因：
- **公平对比**：与现有方法（大多使用均匀分配）进行公平比较
- **简洁性**：证明全局优化框架本身的有效性，无需额外的稀疏度分配策略

#### 2. 非均匀稀疏度（扩展实验）

论文进一步将 ELSA 与两种非均匀稀疏度分配方法对比（在 LLaMA-3-8B @ 70% 稀疏度下）：

| 方法 | 稀疏度分配策略 | C4 PPL |
|------|--------------|--------|
| SparseGPT | 均匀（默认） | 98.35 |
| OWL | 基于异常值分布 | 52.32 |
| EvoPress | 进化搜索 | 33.72 |
| **ELSA（均匀）** | **均匀** | **29.09** |
| ELSA + EvoPress mask | 使用 EvoPress 的非均匀 mask | 29.33 |

**重要发现**：
- ELSA 的**均匀分配**（29.09）优于所有对比方法，包括基于复杂策略的非均匀分配
- 即使使用 EvoPress 发现的非均匀 mask，ELSA 仍略低于其均匀分配版本（29.33 vs 29.09）
- 这说明在 ELSA 的全局优化框架下，**简单的均匀分配已经足够有效**，复杂的非均匀策略反而可能引入次优性

#### 3. N:M 半结构化稀疏（扩展实验）

论文还测试了 ELSA 对硬件友好的 N:M 稀疏模式的适应性：

- **2:4 模式**（每 4 个权重保留 2 个，50% 稀疏度）
- **4:8 模式**（每 8 个权重保留 4 个，50% 稀疏度）

结果显示 ELSA 在这些结构化模式下与现有方法**表现相当**（均约 50% 稀疏度），说明 ADMM 框架可以灵活适配不同的稀疏约束形式。

#### 总结

ELSA 的核心贡献在于**优化框架本身**，而非稀疏度分配策略。实验表明：
- 对于 ELSA 这种全局优化方法，**简单的均匀分配已经能够达到非常好的效果**
- 复杂的非均匀分配（如 EvoPress 的进化搜索）在全局优化框架下可能不再必要
- 框架可以灵活支持 N:M 结构化稀疏等多种约束形式

### Q6: N:M 结构化稀疏时，投影方式需要做什么改进？现有哪些方法针对 N:M 稀疏做了参数调整？

**A: N:M 稀疏的核心改动在投影（Z-update）阶段，需将全局 top-k 选择替换为分组内 top-N 选择。ELSA 框架可以自然适配这一变化(Doubted)。**

#### ELSA 对 N:M 稀疏的适配

##### 1. 约束集合 S 的变化

| 稀疏类型 | 约束集合 S | 数学描述 |
|---------|-----------|---------|
| **非结构化** | 全局 top-k | S = {z ∈ ℝᵈ ‖ ‖z‖₀ ≤ k} |
| **N:M 结构化** | 分组内 top-N | S = {z ∈ ℝᵈ ‖ ∀j ∈ {0,...,d/M-1}, ‖z[jM:(j+1)M]‖₀ = N} |

##### 2. 投影操作的适配

标准投影（Z-update）：

```
z^{t+1} = argmin_{z∈S} ‖x^{t+1}+u^t - z‖₂²
```

- **非结构化**：按绝对值大小全局排序，保留 top-k
- **N:M 结构化**：将参数分成 d/M 组，每组 M 个元素，在每组内按**绝对值大小排序**保留 top-N

##### 3. 目标感知投影的适配

目标感知投影（Fisher 加权）：

```
z^{t+1} = argmin_{z∈S} Σᵢ F̂ᵢᵢ · (zᵢ - (xᵢ^{t+1}+uᵢ^t))²
```

- **非结构化**：按 Fisher 加权贡献全局排序，保留 top-k
- **N:M 结构化**：将参数分成 d/M 组，每组内按**Fisher 加权贡献排序**保留 top-N

##### 4. 论文实验结果

ELSA 测试了两种 N:M 模式（均为 50% 稀疏度）：

| 稀疏模式 | 每组大小 M | 保留数 N | 稀疏度 | 说明 |
|---------|-----------|---------|--------|------|
| **2:4** | 4 | 2 | 50% | NVIDIA 硬件支持 |
| **4:8** | 8 | 4 | 50% | 更灵活的分组 |

结果：ELSA 在 N:M 模式下与现有方法**表现相当**（50% 稀疏度），说明 ADMM 框架的灵活性。但 ELSA 的核心优势（在超高稀疏度下的全局优化能力）在 50% 稀疏度时尚未充分体现。

#### 现有 N:M 稀疏方法

| 方法 | 核心思路 | 与 ELSA 的关系 |
|------|---------|---------------|
| **MaskLLM** (Fang et al., 2024) | 全局优化 N:M mask，基于梯度近似 | 同为全局优化，ELSA 引用并对比 |
| **Neurosurgeon** | 硬件感知的 N:M 自动搜索 | 侧重硬件效率，非精度优化 |
| **AutoN:M** | 自动搜索最优 N:M 配置 | 架构层面的稀疏模式搜索 |
| **SparseGPT/Wanda 变体** | 在逐层剪枝时强制 N:M 模式约束 | 可通过在 mask 生成时加约束实现 |
| **NVIDIA ASP** | 基于绝对值的 2:4 结构化剪枝 | 工业界实际部署方案 |

#### N:M 稀疏的关键挑战

1. **硬件支持**：NVIDIA Ampere+ 架构原生支持 2:4，其他 N:M 模式（如 4:8）需要自定义硬件
2. **精度损失**：N:M 稀疏比同比例的非结构化稀疏造成更大的精度损失，因为它限制了可剪枝的位置
3. **分组策略**：分组可以是连续的（continuous）或打乱的（per-block），打乱分组可能获得更好的精度但破坏硬件兼容性
4. **ELSA 的潜力**：将 ELSA 的目标感知投影与 N:M 约束结合，有可能在 N:M 模式下实现比现有方法更好的精度保持（但论文尚未对此进行深入实验）

#### ELSA 对 N:M 的实现描述

ELSA 论文在附录中有简要说明：

1. **投影步骤的修改**：将约束集合 S 从全局 top-k 改为分组内 top-N
2. **超参配置**：N:M 实验使用与 50% 非结构化稀疏度相同的超参数
3. **实现方式**：在 Z-update 中，将参数分成 d/M 组，每组内按 Fisher 加权贡献排序，保留 top-N

论文**没有提供 N:M 实现的伪代码或更详细的算法描述**，只是说明了框架的可扩展性。这是因为：
- N:M 实验不是 ELSA 的核心贡献（仅在扩展实验中涉及）
- ELSA 的主要贡献在于全局优化框架本身，而非 N:M 结构化稀疏

### Q8: Fisher 全局重要性如何数学表达？如何适配到 N:M 架构？

**A: Fisher 重要性基于 Hessian 的对角近似，每个参数的重要性是独立计算的，可以自然适配到 N:M。**

#### Fisher 重要性的数学推导

ELSA 的核心公式（论文公式 7）：

```
z^{t+1} = argmin_{z ∈ S} Σᵢ F̂ᵢᵢ · (zᵢ - (xᵢ^{t+1} + uᵢ^t))²
```

其中：
- **F̂ᵢᵢ**：经验 Fisher 信息矩阵的对角元素，衡量参数 i 的重要性
- **S**：稀疏约束集合（非结构化或 N:M 结构化）
- **xᵗ⁺¹ + uᵗ**：ADMM 迭代中的"目标点"

##### Fisher 矩阵的来源

1. **理论基础**：Fisher 信息矩阵是 Hessian 的 Gauss-Newton 近似：
   ```
   F = E[∇f(x)·∇f(x)ᵀ] ≈ H (Hessian)
   ```

2. **对角近似**：为了保持可分性（separability），只使用对角元素：
   ```
   Diag(H) ≈ Diag(F) = F̂ᵢᵢ  for each parameter i
   ```

3. **实际计算**：利用 Adam 优化器的 second-moment 估计**免费获取**：
   ```
   F̂ᵢᵢ = E[gᵢ²]  (Adam 中的 v_t，即梯度平方的指数移动平均)
   ```
   > 论文指出："标准 Adam 优化器已经通过 second-moment 估计免费提供了 F̂，无需额外成本"

##### Fisher 重要性的含义

F̂ᵢᵢ 衡量的是**参数 i 对损失函数的二阶贡献**：
- 大 F̂ᵢᵢ：改变参数 i 会导致损失大幅变化 → 参数重要
- 小 F̂ᵢᵢ：改变参数 i 对损失影响小 → 参数不重要

这与 Optimal Brain Surgeon (OBS) 的思想一致：基于 Hessian 而非简单的绝对值来决定剪枝。

#### 适配到 N:M 架构的数学形式

##### 非结构化稀疏

```
S_unstructured = {z ∈ ℝᵈ | ‖z‖₀ ≤ k}

z^{t+1} = argmin_{z ∈ S_unstructured} Σᵢ F̂ᵢᵢ · (zᵢ - (xᵢ^{t+1} + uᵢ^t))²
```

**求解**：全局按 F̂ᵢᵢ 排序，保留 top-k 参数

##### N:M 结构化稀疏

```
S_N:M = {z ∈ ℝᵈ | ∀j ∈ {0,...,d/M-1}, ‖z[jM:(j+1)M]‖₀ = N}

z^{t+1} = argmin_{z ∈ S_N:M} Σᵢ F̂ᵢᵢ · (zᵢ - (xᵢ^{t+1} + uᵢ^t))²
```

由于目标函数是**按参数可分的**（Σᵢ ...），且约束是**按组独立的**，整个问题可以分解为 d/M 个独立的子问题：

```
For each group j:
  z_j^{t+1} = argmin_{z ∈ ℝᴹ, ‖z‖₀=N} Σᵢ₌ⱼᴹ^{(j+1)M-1} F̂ᵢᵢ · (zᵢ - (xᵢ^{t+1} + uᵢ^t))²
```

**求解**：在每组内按 F̂ᵢᵢ 排序，保留 top-N 参数

##### 关键技术点

| 方面 | 说明 |
|------|------|
| **Fisher 计算** | 全局计算（不受 N:M 分组影响），基于整个模型的梯度 |
| **投影操作** | 分组内独立进行，每组内按 Fisher 加权贡献排序 |
| **复杂度** | 与非结构化相同（O(d log d)），只是排序范围从全局变为分组内 |
| **精度** | Fisher 矩阵的全局信息指导每组内的选择，比纯绝对值分组内排序更优 |

### Q9: 介绍 NVIDIA ASP 和 MaxQ 方法

#### NVIDIA ASP (Automatic SParsity)

##### 核心思想

NVIDIA ASP 是 NVIDIA 提出的**基于硬件友好的 2:4 结构化稀疏训练方法**，目标是利用 Ampere 架构的 Sparse Tensor Core 实现 2x 推理加速。

##### 方法流程

```
1. 训练稠密模型 → 获得预训练权重 W_dense
2. 2:4 剪枝 → 基于绝对值大小，将每个权重矩阵剪为 2:4 模式
   W_sparse = W_dense ⊙ M_2:4
   其中 M_2:4 是 2:4 二值掩码（每组 4 个中恰好 2 个为 1）
3. 稀疏微调 → 保持 M_2:4 掩码不变，仅微调非零权重
   初始化 W = W_sparse（稀疏）
   训练时：前向传播用 W（2:4 稀疏格式），反向传播更新非零权重
4. 推理加速 → 使用 NVIDIA cuSPARSELt 库的 2:4-spMM 实现 2x 加速
```

##### 关键技术

1. **Sparse Tensor Core**：Ampere 架构原生支持 2:4 稀疏矩阵乘法，理论 2x 吞吐量
2. **渐进式训练**：分阶段增加稀疏度，让模型逐步适应稀疏约束
3. **与 INT8 量化结合**：2:4 稀疏 + INT8 量化可进一步压缩和加速
4. **腾讯应用**：在腾讯搜索业务中实现 1.3x-1.8x 实际加速

##### 优缺点

| 优点 | 缺点 |
|------|------|
| 硬件原生支持，2x 理论加速 | 只能实现 50% 稀疏度 |
| 工业界验证（腾讯等大规模部署） | 精度损失比非结构化 50% 大 |
| 压缩格式高效（仅存非零值+元数据） | 只能用于推理加速，不能节省训练计算 |
| 流程简单：剪枝+微调 | 仅支持 2:4，不支持其他 N:M 模式 |

#### MaxQ (Multi-Axis Query for N:M Sparsity)

##### 核心思想

MaxQ 是一种基于**多轴重要性查询**的 N:M 稀疏训练方法，针对 CNN（图像任务）设计，解决了现有 N:M 方法未区分权重重要性的问题。

##### 方法流程

```
1. 多轴重要性评估：
   - **卷积核轴 (Kernel Axis)**：评估不同卷积核的重要性
   - **通道轴 (Channel Axis)**：评估不同通道的重要性  
   - **空间轴 (Spatial Axis)**：评估不同空间位置的重要性
   
   通过在多个轴上查询权重的重要性，生成 soft N:M mask

2. 动态 soft mask 生成：
   M_soft = f(W, importance_scores)
   - 重要性高的权重：soft mask 值趋近 1（保留）
   - 重要性低的权重：soft mask 值趋近 0（剪枝）
   - 在训练过程中动态调整

3. 渐进式稀疏训练：
   - 初始阶段：较低的 N:M 稀疏度（如 4:8）
   - 逐步提高稀疏度（如 2:4），让模型逐步适应
   - 类似"退火"过程，避免突然的精度崩溃

4. Soft mask → Hard mask：
   训练结束后，将 soft mask 二值化为 hard N:M mask
   M_hard = argmax(M_soft, 阈值)
```

##### 核心创新

| 创新点 | 说明 |
|--------|------|
| **多轴查询** | 从多个维度（kernel/channel/spatial）评估权重重要性，而非单一维度 |
| **Soft mask** | 使用软掩码代替硬掩码，实现可微的稀疏训练 |
| **渐进式训练** | 逐步增加稀疏度，避免突然冲击 |
| **运行时优化** | Soft mask 可预计算为常量，推理时无额外开销 |

##### 实验结果

- ResNet50 在 ImageNet 上：74.6% Top-1 准确率（1:16 稀疏模式）
- 比现有 SOTA 方法提升 2.8%+
- 覆盖图像分类、目标检测、实例分割等多个任务

##### 与 ELSA 的对比

| 方面 | NVIDIA ASP | MaxQ | ELSA |
|------|-----------|------|------|
| **应用领域** | LLM（推理） | CNN（图像） | LLM |
| **稀疏类型** | 2:4 结构化 | N:M 结构化 | 非结构化/N:M |
| **重要性评估** | 绝对值 | 多轴查询 | Fisher 信息矩阵 |
| **训练方式** | Post-training 微调 | End-to-end 训练 | ADMM 全局优化 |
| **理论深度** | 工程实践 | 经验设计 | 收敛性保证 |

### Q10: 如何通过 Permutation 形成 N:M-friendly 的权重布局？（以 2:4 为例）

**A: 通过通道置换（Channel Permutation），重新排列权重矩阵的输入通道顺序，让重要权重更均匀地分散到各个 N:M 分组中，从而在 N:M 约束下保留更多重要参数。**

#### 核心动机

直接做 2:4 剪枝的问题：如果某 4 个连续通道中有 3 个都很重要，仍必须删除 2 个，造成不可逆的精度损失。

```
原始权重（2:4 直接剪枝）：
通道:    [c0, c1, c2, c3] | [c4, c5, c6, c7]
重要性:  [★★, ★★, ★★, ☆] | [★, ☆, ☆, ☆]
直接2:4: [★★, ★★, ×, ×]  | [★, ×, ☆, ×]  → 删掉了重要的 c2!

置换后（重要通道分散到不同组）：
通道:    [c0, c3, c4, c1] | [c2, c5, c6, c7]
重要性:  [★★, ☆, ★, ★★]  | [★★, ☆, ☆, ☆]
2:4:     [★★, ×, ×, ★★]  | [★★, ×, ☆, ×]  → 保留了所有重要通道!
```

#### 数学表达

##### 线性层的通道置换

对于线性层 Y = XW^T，其中 W ∈ R^(out × in)：

```
原始:  Y = X @ W^T
置换:  Y = (X @ P^T) @ (W @ P)^T = X' @ W'^T

其中:
- P ∈ {0,1}^(in × in): 置换矩阵（每行每列恰一个 1）
- W' = W @ P: 置换后的权重（列重排）
- X' = X @ P^T: 置换后的输入（列重排）
```

**关键**：置换是**无损操作**，数学上 Y 不变。改变的是 W' 中哪些权重被分到同一个 4-组。

##### 优化目标

```
max_P  Σ_{groups g}  Σ_{i ∈ top-2(g)}  importance(W'_g[i])

s.t.   P 是置换矩阵
       W' = W @ P
       groups 按 2:4 划分（每 4 个连续通道为一组）
```

即：找到最优置换 P，使得 2:4 剪枝后保留的权重重要性总和最大。

#### 三类主流方法

##### 方法 1: 启发式置换（E-Sparse, RIA）

**E-Sparse**（腾讯，2023）提出两阶段 shuffle：

```
Step 1: Global Naive Shuffle（全局粗排）
- 按通道重要性排序
- 将重要通道均匀分散到不同 4-组中
- 例如：最重要 → 组0, 次重要 → 组1, ... 第5重要 → 组0

Step 2: Local Block Shuffle（局部微调）
- 将通道分成 n 个 block（每 block 256 通道）
- 在每个 block 内部做局部置换优化
- 搜索空间从 C! 降为 n × 256!
```

**优点**：速度快；**缺点**：贪心策略可能陷入局部最优

##### 方法 2: 可学习置换（PermLLM, 2025 NeurIPS）

**PermLLM** 首次提出端到端可学习的通道置换：

```
Step 1: 松弛化
- 将离散置换矩阵 P ∈ {0,1}^(C×C) 松弛为软置换矩阵 P̃ ∈ [0,1]^(C×C)
- 使用 Sinkhorn 归一化保证 P̃ 是双随机矩阵（行和列和为 1）

Step 2: 端到端优化
- 目标：min_P̃  ||Y_dense - Y_sparse(P̃)||²
- 直接最小化剪枝前后输出的 MSE，而非代理指标
- 通过梯度下降优化 P̃

Step 3: 离散化
- 训练结束后，将 P̃ 通过 Hungarian 算法转为硬置换矩阵 P

Step 4: Block-wise 策略
- 将 C 个通道分成 N_B 个 block，每 block 独立学习置换
- 参数量从 C² 降为 C × B（B 为 block size）
```

**优点**：直接优化真实目标，效果最好；**缺点**：需要训练，计算成本较高

##### 方法 3: 离散优化（Optimal Channel Partition, 2024）

将置换问题形式化为**整数规划**：

```
变量: x[i][g] ∈ {0,1}  (通道 i 是否分配到组 g)
目标: max  Σ_g Σ_{i: x[i][g]=1} importance[i] × retained[i][g]
约束: 
  Σ_g x[i][g] = 1  ∀i    (每个通道恰好分到一个组)
  Σ_i x[i][g] = M   ∀g   (每组恰好 M 个通道)

求解: 列生成法（Column Generation）处理大规模问题
```

**优点**：理论最优；**缺点**：NP-hard，只能处理小规模或近似求解

#### 完整实现流程（以 2:4 为例）

```python
# 伪代码：Permutation + 2:4 Pruning Pipeline

def permutation_aware_2to4_pruning(W, X_calib):
    """
    W: (out_features, in_features) 权重矩阵
    X_calib: 校准数据输入
    """
    # === Step 1: 评估通道重要性 ===
    # 方法 A: 基于权重绝对值
    importance = np.abs(W).sum(axis=0)  # (in_features,)
    
    # 方法 B: 基于激活 (Wanda-style)
    # importance = np.abs(W) * np.norm(X_calib, axis=0)
    
    # 方法 C: 基于 Fisher (ELSA-style)
    # importance = fisher_diagonal(W, X_calib)
    
    # === Step 2: 求解置换矩阵 P ===
    # 启发式：按重要性排序，交错分配到不同组
    P = heuristic_shuffle(importance, group_size=4)
    
    # 或可学习：PermLLM 方式
    # P = learnable_permutation(W, X_calib, group_size=4)
    
    # === Step 3: 应用置换 ===
    W_perm = W @ P  # (out, in)，列重排
    X_perm = X_calib @ P.T  # 输入同步置换
    
    # === Step 4: 2:4 剪枝 ===
    W_sparse = np.zeros_like(W_perm)
    for g in range(in_features // 4):
        group = W_perm[:, g*4:(g+1)*4]  # (out, 4)
        # 每行独立：保留绝对值最大的 2 个
        for row in range(out_features):
            top2_idx = np.argsort(np.abs(group[row]))[-2:]
            W_sparse[row, g*4 + top2_idx] = group[row, top2_idx]
    
    # === Step 5: (可选) 微调恢复 ===
    # W_sparse = finetune(W_sparse, X_perm, ...)
    
    return W_sparse, P  # 返回稀疏权重和置换矩阵

# 推理时：
# Y = (X @ P^T) @ W_sparse^T
# 即：先对输入做置换，再与稀疏权重做矩阵乘法
```

#### 关键技术要点

1. **置换是无损的**：P 是正交矩阵，W @ P 不改变模型表达能力，只改变 N:M 分组方式
2. **推理开销**：置换矩阵 P 可预计算并融合到权重中，推理时**零额外开销**（只需对输入做一次重排，或直接存储置换后的权重）
3. **跨层一致性**：上一层的输出维度置换必须与下一层的输入维度置换保持一致，否则需要在层间插入置换操作
4. **与 ELSA 的结合潜力**：ELSA 的 Fisher 重要性可作为置换优化的目标函数，比绝对值更准确

#### 与 ELSA 的关系

ELSA 论文**未使用通道置换**，直接在原始通道顺序上做 N:M 剪枝。如果将置换技术与 ELSA 结合：

```
ELSA + Permutation 的潜在流程:
1. 计算 Fisher 重要性 F̂ (全局)
2. 基于 F̂ 求解最优置换 P (PermLLM 式可学习置换)
3. W' = W @ P
4. 在 W' 上运行 ADMM + Fisher 加权投影 + 2:4 约束
5. 推理时: Y = X @ P^T @ W'_sparse^T
```

这可能是未来提升 ELSA 在 N:M 模式下性能的有前景方向。
