## 📌 核心摘要

本文提出 **LSA (Layer-wise Sparsity Allocation)**，一种面向大语言模型 (LLM) 剪枝的逐层稀疏分配方法。与现有方法 (OWL、DLP) 依赖权重幅度或人工设计的评分代理来估计层重要性不同，LSA 通过评估每个 Transformer 层在移除 50% 最不重要权重后的 **最小线性重建误差 (Minimal Linear Reconstruction Error, LSE)** 来直接量化层重要性，再将层重要性映射为各层的稀疏率。

**核心优势**：LSA 不仅支持传统的逐层 (layer-wise) 稀疏分配，还支持更细粒度的 **逐块 (block-wise)** 和 **逐投影 (projection-level)** 稀疏分配，在不引入显著性能退化的前提下捕获更精细的冗余分布。在 70% 整体稀疏率下，LSA 在语言建模任务和七个零样本任务上超越了 SparseGPT、Wanda、OWL、DLP 等主流方法。

## 🎯 研究动机与问题

### 背景：LLM 剪枝中的稀疏分配

LLM 剪枝 (如 SparseGPT、Wanda) 通常采用 **逐层独立剪枝** 范式以降低内存开销。在此框架下，一个关键设计选择是：**如何将全局稀疏预算分配到各层？**

| 分配策略 | 代表方法 | 原理 | 局限 |
|----------|----------|------|------|
| **均匀分配** | SparseGPT、Wanda 默认 | 所有层相同稀疏率 | 忽略层间敏感度差异，高稀疏下性能急剧下降 |
| **基于激活异常值** | OWL | 按激活异常值比例分配稀疏率 | 依赖启发式，无异常值时退化 |
| **基于权重评分** | DLP | 用精心设计的评分代理估计层重要性 | 代理与真实性能的错位 |

### 现有方法的两大缺陷

1. **代理目标错位**：OWL 和 DLP 依赖权重幅度或人工设计的评分代理 (score proxies) 来估计层重要性，而非直接衡量剪枝对层信息量的影响。这些代理指标与模型真实性能之间可能存在偏差。

2. **粒度受限**：现有方法强制同一层内的所有 block 和投影权重使用相同稀疏率，以避免性能退化。这忽略了层内不同模块 (attention vs. MLP) 和不同 block 之间的冗余差异，限制了高稀疏率下的性能上限。

### LSA 的核心思路

**直接量化"剪掉会损失多少信息"**：与其用间接的代理指标，不如直接测量——如果移除一个层中 50% 最不重要的权重，该层的输出会偏差多少？这个偏差（即最小线性重建误差 LSE）就是该层重要性的直接度量。

- LSE 大 → 该层对剪枝敏感 → 应分配较低稀疏率（保留更多权重）
- LSE 小 → 该层冗余度高 → 应分配较高稀疏率（可剪掉更多权重）

## 💡 方法：LSA 框架

### 1. 最小线性重建误差 (LSE) 的计算

对于每个 Transformer 层，LSA 评估其在移除部分权重后的重建能力：

```
对每个层 ℓ:
  1. 使用 Wanda 式的权重重要性评分 (|W|·||X||) 确定该层最不重要的 50% 权重
  2. 将这些权重置零，得到稀疏权重矩阵 W̃_ℓ
  3. 用原始输入 X_ℓ 计算稀疏后的输出: Ȳ_ℓ = W̃_ℓ · X_ℓ
  4. 寻找最优重建矩阵 R*, 使得 R* · X_ℓ 尽可能逼近原始输出 Y_ℓ = W_ℓ · X_ℓ
     R* = argmin_R ||R · X_ℓ - Y_ℓ||²_F
  5. 最小线性重建误差: LSE_ℓ = ||R* · X_ℓ - Y_ℓ||²_F
```

**关键点**：
- 引入重建矩阵 R 是为了允许剩余权重"补偿"被移除权重的影响，因此测量的是 **最小** 重建误差（即最好的情况下的误差）
- 如果即使最优重建也无法弥补（LSE 大），说明该层确实重要
- 如果轻易就能重建（LSE 小），说明该层冗余度高

### 2. 从层重要性到稀疏率映射

将各层的 LSE 转换为稀疏率分配：

```
给定全局稀疏率 S_global 和层数 L:

  1. 计算每层的 LSE_ℓ (ℓ = 1, ..., L)
  2. 将 LSE 归一化为重要性权重: w_ℓ = LSE_ℓ / Σ LSE_j
  3. 稀疏率分配: S_ℓ = f(w_ℓ, S_global)
     - 重要性高 (w_ℓ 大) → S_ℓ 低 (少剪)
     - 重要性低 (w_ℓ 小) → S_ℓ 高 (多剪)
  4. 约束: (1/L) Σ S_ℓ = S_global  (满足全局稀疏预算)
```

### 3. 多粒度稀疏分配

LSA 的一个重要创新是支持三个层级的稀疏分配：

| 粒度 | 分配单元 | 适用场景 | 效果 |
|------|----------|----------|------|
| **Layer-wise** | 整个 Transformer 层 | 基础分配 | 已优于 OWL/DLP |
| **Block-wise** | 层内每个 attention/MLP block | 层内模块冗余不均时 | 进一步提升性能 |
| **Projection-level** | 每个投影权重矩阵 (Q/K/V/O/FFN) | 细粒度冗余分布 | 最高性能 |

**核心优势**：在更强的模型 (如 Qwen3-8B) 上，OWL 和 DLP 甚至不如均匀分配，而 LSA 的细粒度变体仍能超越均匀分配，证明其能更准确地捕获冗余。

### 4. 与现有剪枝框架的兼容性

LSA 是一个 **即插即用的稀疏分配模块**，可与多种剪枝框架配合：

```
基线剪枝方法 (任选):
  ├── SparseGPT  →  LSA 替换其默认均匀分配
  ├── Wanda      →  LSA 替换其默认均匀分配
  └── ADMM       →  LSA 提供层间稀疏约束

分配增强 (可叠加):
  └── AlphaPruning + LSA  →  结合谱形状指标与重建误差
```

## 💬 个人理解与点评

### 技术亮点

1. **直接度量优于间接代理**：LSA 的核心洞察是——与其用权重幅度、异常值比例等间接指标猜哪层重要，不如直接测量"剪掉一半后重建误差有多大"。这种"直接测量"的思路简洁且有效，与 ELSA (ADMM 全局优化) 的"直接优化真实目标"理念异曲同工。

2. **多粒度分配的实用性**：论文发现更强的模型 (Qwen 系列) 上，传统的层级分配 (OWL/DLP) 甚至不如均匀分配，而 LSA 的 block-wise / projection-level 变体仍能获益。这说明随着模型变强，冗余分布变得更加不均匀，需要更细粒度的分配策略。

3. **即插即用的兼容性**：LSA 不绑定特定剪枝方法，可作为 SparseGPT、Wanda、ADMM、AlphaPruning 的稀疏分配模块，实用性强。

### 与相关方法的对比

| 方法 | 层重要性度量 | 粒度 | 是否需要反向传播 | 与 LSA 的关系 |
|------|-------------|------|------------------|--------------|
| **OWL** | 激活异常值比例 | 层级 | 否 | LSA 的直接对比基线 |
| **DLP** | 权重评分代理 | 层级 | 否 | LSA 的直接对比基线 |
| **AlphaPruning** | 谱密度形状指标 (HT-SR) | 层级 | 否 | 可与 LSA 叠加使用 |
| **ELSA** | ADMM 全局优化 | 全局 | 是 (优化器) | 不同路线：ELSA 优化全局目标，LSA 优化分配策略 |
| **LSA** | 最小线性重建误差 | 层/块/投影 | 否 (前向+最小二乘) | 本文方法 |

### 潜在限制

1. **LSE 计算的假设**：用 50% 作为评估稀疏率来计算 LSE，但最终目标稀疏率可能是 70% 或 90%。评估稀疏率与目标稀疏率不一致可能引入偏差。
2. **仍为非结构化稀疏**：LSA 产生非结构化稀疏模式，实际加速需要稀疏矩阵库支持。
3. **层间依赖未建模**：LSE 是逐层独立计算的，未考虑层间误差传播 (cf. "Beyond Layer Importance" (arXiv:2606.15161) 揭示的层间扰动吸收现象)。

## 💬 深度问答 (Q&A)

### Q1: 为什么用 50% 稀疏率计算 LSE，而不是直接用目标稀疏率 (如 70%)？

**A: 50% 是一个"中性探针"，用于衡量层的固有敏感度，而非特定稀疏率下的表现。**

- 如果用目标稀疏率 (如 70%) 计算 LSE，那 LSE 就和目标强耦合——不同目标稀疏率需要重新计算所有层的 LSE
- 用固定的 50% 作为评估点，LSE 反映的是层的"固有重要性"（类似材料力学中的屈服强度测试），与最终分配的目标稀疏率解耦
- 50% 是一个折中：太小 (如 10%) 时所有层 LSE 都很小，区分度不够；太大 (如 90%) 时所有层 LSE 都很大，也难区分

### Q2: LSA 的最小线性重建误差与 SparseGPT 的重建误差有何区别？

**A: 两者度量目标不同——SparseGPT 优化"如何剪"，LSA 评估"该剪多少"。**

| 维度 | SparseGPT | LSA |
|------|-----------|-----|
| **目的** | 在给定稀疏率下找到最优的权重掩码 | 确定每层应该分配多少稀疏率 |
| **重建误差的角色** | 最小化 (优化目标) | 测量 (评估指标) |
| **是否引入重建矩阵 R** | 否 (直接修改 W) | 是 (允许 R 补偿被移除权重) |
| **输出** | 稀疏权重矩阵 | 层间稀疏率分配方案 |

LSA 引入重建矩阵 R* 是关键区别：它允许"剩余权重重新调整以补偿被移除权重"，因此 LSE 测量的是"即使最优补偿后仍无法避免的误差"，更能反映层的固有重要性。

### Q3: 为什么在更强的模型 (Qwen 系列) 上 OWL/DLP 反而不如均匀分配？

**A: 强模型的冗余分布更复杂，简单的层级代理指标失效。**

- OWL 基于激活异常值比例分配——但强模型的异常值分布可能不再与层敏感度正相关
- DLP 基于权重评分代理——强模型中权重分布更均匀，评分代理的区分度下降
- 强模型中，冗余更多分布在层内不同模块之间 (attention vs. MLP) 而非层间，因此需要 block-wise / projection-level 的细粒度分配

这也解释了为什么 LSA 的细粒度变体在强模型上优势更大。

### Q4: LSA 与 ELSA (arXiv:2510.01650) 的关系是什么？

**A: 两者解决不同层面的问题，可视为互补关系。**

| 维度 | LSA | ELSA |
|------|-----|------|
| **核心问题** | 如何分配层间稀疏率 | 如何在给定稀疏约束下全局优化权重 |
| **优化层面** | 稀疏分配策略 | 权重更新与掩码选择 |
| **是否需要训练** | 否 (前向传播 + 最小二乘) | 是 (ADMM 迭代优化) |
| **适用场景** | 快速一次性剪枝 | 追求极限稀疏度 (90%+) |

理论上，可以用 LSA 确定层间稀疏分配，再用 ELSA 在该分配下进行全局优化——论文 rebuttal 中也提到 LSA 可与 ADMM 框架集成。

### Q5: LSE 使用 layer-wise F-norm 度量，不同层之间的 error 会不会存在量级上的差异？

**A: 会存在量级差异，这是 F-norm 作为绝对度量固有的问题，但在实际中部分被 Transformer 架构缓解。**

#### F-norm 量级受三个因素影响

LSE 的计算为 `LSE_ℓ = ||R* · X_ℓ - Y_ℓ||²_F`，F-norm 是对所有元素的**平方和**，因此量级取决于：

| 因素 | 影响机制 | 在 Transformer 中的实际情况 |
|------|----------|---------------------------|
| **激活幅度** ‖X_ℓ‖ | X 越大，误差绝对值越大 | 现代 LLM (LLaMA/Qwen) 用 pre-RMSNorm，激活在进入权重矩阵前被归一化，**层间差异较小** |
| **权重幅度** ‖W_ℓ‖ | W 越大，被移除权重的绝对影响越大 | 训练良好的 LLM 层间权重幅度通常较均匀，但并非严格一致 |
| **矩阵维度** | F-norm 对所有元素求和，大矩阵天然有更大的 F-norm | 同层内 attention 的 Q/K/V/O (d×d) 和 MLP 的 down (d×d_ff) 维度不同，**这是主要量级差异来源** |

#### 核心风险

如果一个层的激活或权重幅度恰好比其他层大 10×，那么即使该层的"相对重建质量"和其他层一样好（相对误差相同），其 LSE 也会大 100×（因为是平方求和），从而被误判为"更重要"。

#### 实际缓解因素

1. **RMSNorm 的隐式归一化**：pre-norm 架构中，每层输入已被归一化，激活幅度差异较小
2. **层间结构一致性**：LSA 主要在**层间**比较（而非层内 attention vs. MLP），而同构的 Transformer 层有相同的维度结构，量级差异相对可控
3. **可能的相对归一化**：论文可能使用 `LSE_ℓ / ||Y_ℓ||²_F` 来归一化（论文正文未明确，但这是合理推测），消除输出幅度的影响

#### 但细粒度分配时问题更突出

在 block-wise 或 projection-level 分配中，attention 的 O 矩阵 (d×d) 和 MLP 的 down 矩阵 (d×d_ff，通常 d_ff = 4d) 维度差异很大，F-norm 不可直接比较。这可能解释了为什么细粒度变体需要额外的设计考量。

### Q6: 为什么不用最后的 loss（如 NTP loss）作为指导？

**A: NTP loss 是真实优化目标，但存在计算成本、信号污染和循环依赖三大问题。LSE 作为局部代理是效率与信号纯度的权衡。**

#### 原因一：计算成本不可承受

```
用 NTP loss 评估 L 个层的重要性:
  for ℓ = 1 to L:
    1. 剪枝层 ℓ (移除 50% 权重)
    2. 完整前向传播 (层 1 → 层 L)   ← 瓶颈
    3. 计算 NTP loss (需 vocab 投影, vocab ~32k-128k)
    4. 恢复层 ℓ
  总成本: O(L) 次完整前向传播 + L 次 vocab 投影

用 LSE 评估 L 个层的重要性:
  1. 单次前向传播，收集所有层的输入 X_ℓ
  2. for ℓ = 1 to L: 计算 LSE_ℓ (仅涉及该层的局部矩阵运算)
  总成本: 1 次前向传播 + L 次局部最小二乘
```

对于 32 层的 7B 模型，NTP loss 方案需要 32 次完整前向传播，LSE 只需 1 次。

#### 原因二：NTP loss 混杂了"层敏感性"和"下游补偿能力"

这是更本质的问题。剪枝层 ℓ 后的 NTP loss 变化是两个效应的叠加：

```
ΔNTP_ℓ = (层 ℓ 自身的敏感性) × (下游层的补偿/放大系数)
```

"Beyond Layer Importance" (arXiv:2606.15161) 的实验揭示：**早期层的扰动会被中后期层"吸收"**。因此：

- 剪枝早期层 → NTP loss 变化可能很小（不是因为早期层不重要，而是因为下游层补偿了）
- 剪枝后期层 → NTP loss 变化可能更大（因为没人补偿了）

如果用 NTP loss 指导分配，会**低估早期层的重要性、高估后期层的重要性**，导致给早期层分配过高稀疏率——这恰恰是错误的！

**LSE 的优势在于它是"局部纯信号"**：只测量层 ℓ 自身的重建能力，不被下游补偿效应污染。对于"决定哪层该多剪/少剪"这个任务，局部信号反而更直接。

#### 原因三：循环依赖问题

```
NTP loss 方案: 要知道层 ℓ 重要性 → 需剪枝层 ℓ → 需知道剪哪些权重 → 需知道稀疏率
              但稀疏率正是我们要分配的！  (鸡生蛋问题)

LSE 方案: 用固定的 50% 评估所有层 → 得到相对重要性 → 映射到目标稀疏率
          (无循环依赖)
```

#### NTP loss 的不可替代优势

NTP loss 是最真实的优化目标。ELSA (arXiv:2510.01650) 正是直接优化 NTP loss (通过 ADMM)，在 90%+ 极限稀疏下大幅超越 LSE 类方法。代价是 7.12 GPU-hours (7B 模型)，远高于 LSA 的成本。

#### LSE vs. NTP loss 对比总结

| 维度 | LSE (LSA 使用) | NTP loss |
|------|----------------|----------|
| **度量层面** | 局部（单层重建误差） | 全局（端到端预测损失） |
| **是否被下游补偿污染** | 否 | 是 |
| **计算成本** | 1 次前向 + L 次局部运算 | L 次完整前向 + vocab 投影 |
| **与真实目标的对齐度** | 代理（间接） | 真值（直接） |
| **极限稀疏度表现** | 70% 表现好，90%+ 未充分验证 | 90%+ 仍保持性能 (ELSA) |
| **适用场景** | 快速一次性剪枝 | 追求极限压缩 |

**一句话总结**：LSA 选择 LSE 是在**计算效率**和**信号纯度**（不被补偿效应污染）之间的合理权衡，代价是放弃了与真实优化目标的直接对齐。
